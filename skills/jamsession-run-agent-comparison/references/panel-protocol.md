# Optional assisted planning comparison

Use only when the user requests a panel or assisted extension. Existing solo
trials do not authorize new participants, controls, drafts or evaluation calls.
Freeze the panel membership, exact harness/settings, role/order, two review
rounds, turn limits, source access and expected final count before launch.

A reusable design starts from each constituent's lowest-scoring usable solo
plan for the same task and frozen source. Predeclare ties by stable trial ID.
Reuse those preserved plans; do not buy new initial drafts. Keep seed score,
identity map and selection rationale coordinator-private. Participants receive
only metadata-redacted seed content, task and permitted source, never grades,
expert checklists, source adjudications or historical answers. Label this as
assistance targeted at weak seeds; it is not a random sample of solo work.

For each of two rounds, order a designated contrarian first, other participants
next and the first-listed noncontrarian lead last. A pair has the second member
review first and the lead integrate last. A triple without a contrarian has the
other listed members review before the lead. Freeze an explicit order instead
if the requested roles differ. A continuing participant session across rounds
is assisted context, not a fresh independent solo trial.

Each reviewer reads the current plan, checks concrete issues against allowed
source and returns concise actionable findings or a justified no-change result.
The lead integrates each round into a complete coherent plan and identifies
unresolved choices honestly. Challenges are evidence-based; no requirement to
invent disagreement or agree with a reviewer. Preserve accepted turns, public
finals, sessions, recovery invocations and final artifact hashes separately.

Evaluate final plans with the same frozen rubric and fresh blind premium review
protocol as solo plans. Hide seed scores and panel identities from graders.
If a final is missing, report it unavailable, not a zero. Publish each panel
final as n=1 in a separate assisted cohort; never pool it into constituent solo
averages or invent a panel bugfix/overall result for a feature-only task.

A report may show final score, best constituent seed score and Gain. Label Gain
as the final score minus the best of the constituent seeds selected for lowest
solo scores in a prior grading batch, not matched random controls or a fresh
blind paired estimate. Disclose membership/settings and all additional work. An observed gain
in a deliberately selected weak seed does not establish causality, reliability
or the panel's population advantage. Keep candidate and grader cost separate.
