# Coordinate Agent Work

Default to one accountable owner carrying a coherent task through implementation,
checks, corrections and authorized handoff. Talking with the human does not make
that session a permanent supervisor or prohibit it from implementing. A follow-up
changes the task or priority, not automatically the owner. Continue the existing
owner/session across phases; compaction, small corrections or a slow response do
not justify replacing it.

Delegate when a concrete independent question, specialist review or disjoint task
benefits from another agent. Do not create a supervisor/manager/worker hierarchy
merely because delegation is available. A queue coordinator or host resource owner
may be necessary for actual shared scheduling; use the repository's existing
owner rather than adding another layer. Delegation being unavailable does not
block the authorized owner from doing its own work.

Before sending code or context, use `jamsession-summon-agent` for provider consent,
current availability and explicit model, effort and access. Honor the user's
model choices; use `jamsession-model-recommendations` otherwise. Use
`jamsession-use-remote-agent-over-ssh` for authorized remote work.

Give each delegation an objective, bounded ownership, inputs, access level,
checks, return route, stopping conditions and commit authority. A delegated leaf
performs that assignment directly; it does not recursively staff managers or
workers without explicit delegation authority. Independent read-only help is
optional, not a required workflow for each phase. Full-task ownership may be
explicitly delegated, including implementation and handoff.

Keep one writer per checkout. Parallel writers require distinct authorized
workspaces and disjoint tasks. Preserve foreign edits, claims, actual writer
locks and runtime/port/cache/measurement boundaries. Source ownership is not
permission for tests, deployment, unrelated tasks or shared-resource takeover.
Same-owner continuation is not a new checkout allocation: do not reset/sync Git,
require a fresh phase token or audit foreign helper descriptors merely to keep
working under unchanged custody. Follow repository guards for real transfer,
initial allocation and release. A retained writer lock or uncertain native
completion must never be bypassed.

Use the existing task record for concise ownership, decisions and evidence; do
not invent a coordination ledger, mandatory inbox or duplicate worksheet.
Resolve reversible in-scope decisions using the task's rules. Escalate actual
missing authority or consequential unresolved choices, not effort alone.

Wait through exact returned process/job handles or a yielding completion notice.
Do useful independent work between meaningful checkpoints; do not poll or message
for reassurance. A delivery acknowledgement, wrapper exit or elapsed time is not
native completion. Preserve uncertainty and never resend an uncertain input.
Accept results by inspecting the actual diff/evidence and required checks. Return
concise outcomes, exact source commits and material limits; publish only within
the task's authority.
