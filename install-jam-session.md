description: Installation prompt for installing the Jam Session CLI and skills
---

Jam Session is a tiny CLI your favorite coding agent uses to summon other coding agents, and some useful skills and workflows that this enables.

Install Jam Session by following https://jamsession.jamon.dev/install.md (or https://github.com/jamonholmgren/jamsession/blob/main/install.md), then onboard and teach the user to use it effectively.
