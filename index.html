Summon other agents.

A tiny CLI your coding agent uses to call Codex, Claude, Cursor, Grok, and Copilot — plus skills for multi‑agent planning, review, panels, and delegation.

macOS · Linux · WSL — totally free, MIT licensed.

Getting started

Let your agent install Jam Session. Paste this prompt into your coding agent:

Install Jam Session by following https://jamsession.jamon.dev/install.md, then onboard.

Your agent installs it, reads the docs, and teaches you the ropes. That’s the whole onboarding.

Or do it yourself:

curl -fsSL https://jamsession.jamon.dev/install.sh | sh

Then check every provider and its available usage:

jamsession status

status combines readiness and subscription usage. For automation, use jamsession usage --json; for focused authentication diagnostics, use jamsession doctor.

What a jam looks like

I’ve been creating and curating a set of skills and scripts since late 2025 and wanted to share a few of my most useful with my friends in the coding community. That’s where Jam Session came from.

My favorites are ping-pong-planning and orchestrate-agent-work. I don’t think a day goes by that I’m not using those.

I’d love to hear how you’re using Jam Session! Send me a tweet or an email at jamsession at jamon.dev.

Jamon

No dependencies.

No runtime stack

Jam Session is just a few Bash scripts and Markdown skill files. Even provider usage reporting needs no Python, database, or added packages.

Use your favorite agent

This isn’t an app or a TUI. Your favorite coding agent uses the CLI to call and coordinate agents from other providers — you keep working the way you already do.

Skills in the box

Each skill teaches your agent how to jam with the others. It’s how Jamon likes to do work.

  • Summon agent Starts or resumes a provider-native agent session. jamsession-summon-agent
  • Ping-pong planning Agents challenge and refine a plan in sequence. jamsession-ping-pong-planning
  • Contrarian review An adversarial reviewer tries hard to break the work. jamsession-contrarian-review
  • Agent panels Independent agents answer, then your agent synthesizes. jamsession-ask-agent-panel
  • Orchestrator Runs managers and workers for autonomous, parallel work. jamsession-orchestrate-agent-work
  • Agent Worksheet Keeps durable task state so another agent can pick up the work. jamsession-use-agent-worksheet
  • Individual Worker Workflow Keeps one assigned worker bounded and verifiable. jamsession-individual-worker-workflow
  • Work Over SSH Performs a scoped task directly in a remote checkout. jamsession-work-over-ssh
  • Use Remote Agent Over SSH Runs a Jam Session agent inside a remote checkout. jamsession-use-remote-agent-over-ssh
  • Agent usage Shows provider quotas, remaining capacity, and reset times. jamsession-get-agent-usage
  • Model recommendations Chooses Jamon’s preferred model for each kind of work. jamsession-model-recommendations

Easy to extend

If your favorite agent isn’t on the roster yet, a provider adapter is small enough that your agent can scaffold and fill one in. Paste this into your agent:

Use the jamsession CLI to add a new provider adapter. Ask me which provider CLI I want to add, and make sure it is already installed and authenticated. Run jamsession help make-adapter first, then create and test the adapter.

If your Jam Session provider adapter is working well for you, please have your agent open a pull request! I’d love to support more agent providers.
