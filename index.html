Summon other agents.

A tiny CLI your coding agent uses to call Codex, Claude, Cursor, Grok, and Copilot — plus skills for multi‑agent planning, review, panels, and delegation.

curl -fsSL https://jamsession.jamon.dev/install.sh | sh

macOS · Linux · WSL — totally free, MIT licensed.

What a jam looks like

I’ve been using Jam Session for months now, happy to open source it!

You can have your agent summon other agents and it gives them a consistent CLI and some really useful skills for basic orchestration.

Check it out: https://jamsession.jamon.dev

— Jamon Holmgren

No dependencies.

No runtime stack

Jam Session is a few Bash scripts and Markdown skill files. It needs Bash and the provider CLIs you already use — and nothing else. No service, no daemon, no Python, no Node, no database, and no API keys of its own.

Use your favorite agent

This isn’t an app or a TUI. Your favorite coding agent uses the CLI to call and coordinate agents from other providers — you keep working the way you already do.

Getting started

Install it yourself with the one-liner above — or skip the manual and let your agent do it. Paste this prompt into your coding agent:

Install Jam Session by following https://jamsession.jamon.dev/install.md, then show me how to use it to summon other coding agents.

Your agent installs it, reads the docs, and teaches you the ropes. That’s the whole onboarding.

Skills in the box

Each skill is a Markdown file that teaches your agent a way to jam with the others.

  • Summon agent Fire one prompt at one agent and get the answer back. jamsession-summon-agent
  • Ping-pong planning Two agents volley a plan back and forth until it holds up. jamsession-ping-pong-planning
  • Contrarian review A rival agent tries hard to poke holes in your work. jamsession-contrarian-review
  • Agent panels Ask several agents the same question, compare the takes. jamsession-ask-agent-panel
  • Delegation Supervisor, managers, workers — big jobs split across agents. jamsession-orchestrate-agent-work
  • Worker slices Give one agent a bounded piece of work with a clear handoff. jamsession-execute-agent-slice
  • Scoped SSH work Do tightly scoped work directly on another authorized machine — no agent needs to run there. jamsession-work-over-ssh
  • Remote agents Launch agent sessions running elsewhere and check back in. jamsession-run-remote-agents
  • Model selection Agents weigh a named, dated recommendation pack against native provider availability, then make and record the actual provider, model, and effort choice. Recommendations never become run defaults. jamsession-select-agent-model

Easy to extend

If your favorite agent isn’t on the roster yet, a provider adapter is small enough that your agent can scaffold and fill one in. Paste this into your agent:

Use the jamsession CLI to add a new provider adapter. Ask me which provider CLI I want to add, and make sure it is already installed and authenticated. Run jamsession help make-adapter first, then create and test the adapter.
